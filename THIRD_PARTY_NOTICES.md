# Third-party notices

This repository contains original OpenSageTV Vibe plugin and launcher code.
It compiles against the Apache-2.0 SageTV plugin API but does not redistribute
`Sage.jar`.

The separately packaged FFmpeg/MIM runtime contains FFmpeg and its enabled
libraries. Their source, configuration, licenses, and notices remain owned by
the `opensagetv-vibe-ffmpeg-mim` project and must accompany every runtime
release.
